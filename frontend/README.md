# Frontend

Ide kerül majd az Angular alkalmazás. Angular projekt még nincs létrehozva.

- `public/`: a korábbi HTML/CSS/JavaScript felület.
- `test/browser/`: a meglévő felület böngészős tesztjei.

A korábbi felület a projekt gyökeréből `npm start` paranccsal próbálható ki. A `npm run start:api` csak a backendet indítja. A böngészőtesztek parancsa a gyökérből: `npm run test:e2e`.

A későbbi Angular-kapcsolódás leírása: [Backend dokumentáció](../docs/backend.md).
